# apps/core-web/src/assets/brand

Up: [assets](../README.md)

## Purpose

Brand vectors of the web console: the DEMS emblem (shield and fingerprint) and the topographic background texture. Both are original vector work in this repository (per their header comments).

## Files

| File | Role |
|---|---|
| [`emblem.svg`](emblem.svg) | DEMS emblem, 128 x 128: one shield path (double rim) and six fingerprint ridges `emblem-arc-1` to `emblem-arc-6`, sharing one vertical gold gradient. Hand-authored. Its header states the animation contract (draw order from the core ridge outwards) and that `packages/shared/src/brand/emblem.ts` mirrors its path data, so each `d` attribute stays on one line. No console source file imports it directly. |
| [`topo.svg`](topo.svg) | Topographic texture, 240 x 280. GENERATED by `packages/shared/scripts/gen-topo.ts` (seed 20261001); do not edit, regenerate with `npm run gen:topo -w @dems/shared`. Imported by `components/shell/sidebar.tsx` (`topoUrl`) and used as a background in `features/login/login.css`. |

## Main exports

None (SVG files). `topo.svg` is consumed as a URL import by the shell sidebar and the login stylesheet.

## Core operations, state and shared modules

- No Core operation and no state.
- Related shared code: `packages/shared/src/brand/emblem.ts` (emblem path data) and `packages/shared/scripts/gen-topo.ts` (generator of `topo.svg`).
- Console users: [`../../components/shell/`](../../components/shell/README.md) and [`../../features/login/`](../../features/login/README.md).
