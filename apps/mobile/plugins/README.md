# `apps/mobile/plugins`

Up: [apps/mobile README](../README.md)

## Purpose

Local Expo config plugins, applied by `expo prebuild` through `app.json`. They change the generated Android project, so their effect survives a regenerated `android/` folder.

## Contents

| Entry | Role |
|---|---|
| `with-dems-core-cleartext.js` | Local Expo config plugin: cleartext http/ws so the tablet reaches a user-configured LAN Core (for example `http://192.168.x.x:4420`); keeps the loopback domain-config. |
| `with-dems-core-cleartext.test.ts` | Test: The release build permits cleartext http/ws in base-config so the user-configured LAN Core is reachable. The loopback domain-config is kept, the plugin never sets `usesCleartextTraffic`, adds no ... |
| `with-dems-library-patches.js` | Local Expo config plugin: the Android build refuses to run with an unpatched library. `apps/mobile/android/` is regenerated by `expo prebuild`, so the guard is re-applied here as one marked block at the end of ... |
| `with-dems-release-signing.js` | Local Expo config plugin: DEMO release signing for the packaged APK. `apps/mobile/android/` is regenerated by `expo prebuild` (F-21), so hand edits to `android/app/build.gradle` are not durable. This plugin ... |

## Tests

`with-dems-core-cleartext.test.ts` sits beside the plugin. Run with `npm test -w @dems/mobile`.
