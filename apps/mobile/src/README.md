# `apps/mobile/src`

Up: [apps/mobile README](../README.md)

## Purpose

The source tree of the tablet app (`@dems/mobile`). Expo Router reads the routes from `app/`; every screen body lives in `features/`; `runtime/` is the one place that knows where the Core server is and how the app talks to it. The other folders are shared building blocks (auth, navigation shell, providers, components, layout, motion, i18n, small helpers).

Import alias: `@/` points at this folder (for example `@/runtime`, `@/features/pairing/pairing-screen`). Shared contract code (typed client, simulator, words, tokens) comes from `@dems/shared/*` in `packages/shared`.

## Contents

| Entry | Role |
|---|---|
| [`app/`](app/README.md) | Expo Router routes. |
| [`auth/`](auth/README.md) | The sign-in layer of the app, one level below the runtime provider. |
| [`components/`](components/README.md) | Shared UI building blocks used by many features. |
| [`features/`](features/README.md) | One folder per screen area. |
| [`i18n/`](i18n/README.md) | The app's i18n runtime: i18next and react-i18next, English only. |
| [`layout/`](layout/README.md) | Layout helpers: the layout class (compact, medium, expanded) from the window size in dp, the navigation chrome it implies, `SafeScreen` (the screen root with safe-area edges and the `screen-<id>` test id) and `PaneLayout` for the list-and-detail panes that re-flow on rotation and split screen. |
| [`lib/`](lib/README.md) | Small shared helpers that are not a feature: the version a footer shows, the Core's component versions (operation 64 `getSystemStatus`), the hand-off mark between two session screens, the soft keyboard rules, list position keeping, operator-scoped query keys, confirmed bottom-sheet opening and the tone icon map. |
| [`motion/`](motion/README.md) | The motion kit: shared motion tokens mapped to Reanimated, value and layout animation builders, the motion policy (full, reduced, slow; OS setting and in-app override), ambient loop registry, the haptics service (the only caller of `expo-haptics`), the glow layer, the `?debug=1` performance overlay and the watch over the UI animation runtime. |
| [`navigation/`](navigation/README.md) | The navigation shell: the root navigator with the auth guard and the pairing gate, the route registry (tabs on phones and tablets), stacks, master-detail selection, deep-link parameter parsing, the pending href of a guarded link, session guards and session-state routing, the back guard, the route error fallback and the rail collapse preference. |
| [`providers/`](providers/README.md) | The app's provider tree and boot: `AppProviders` (keyboard, safe area, query client, i18n, HeroUI Native, the shared heartbeat, then the runtime's `SimRuntimeProvider` and the `AuthProvider`; the motion policy provider sits around it in `app/_layout.tsx`), `BootGate` (holds the native splash during hydration, then shows the boot skeleton) and the toast area offsets. |
| [`runtime/`](runtime/README.md) | The data source of the app and its wiring. |
| `env.d.ts` | Committed type declarations (CSS side-effect imports) so `tsc --noEmit` passes on a clean checkout. |
| `global.css` | Global styles: kit styles first, then the generated design theme. |
| `uniwind-types.d.ts` | Generated by Uniwind; not edited by hand. |
