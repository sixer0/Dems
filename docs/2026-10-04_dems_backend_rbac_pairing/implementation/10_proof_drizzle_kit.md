| S-1 | drizzle-orm 0.45.3 has **no built-in `bytea` column** (`node_modules/drizzle-orm/pg-core/columns/` has no such file). `customType` works; the DDL quotes the type name (`"token_hash" "bytea"`), which resolves because the catalog name is lower-case | Declare one shared `bytea` custom type with `data: Buffer; driverData: Buffer`. | S-2 | The migrator splits a file on the text `--> statement-breakpoint` wherever it occurs, **also inside a comment** (`node_modules/drizzle-orm/migrator.js:16`). | S-3 | `migrate()` runs **all pending files in one transaction** (`dialect.js:60-71`). A failure in the last file rolls back the earlier ones; `id` values of the migrations table then have gaps | Consistent with MG-7. A half-applied set cannot exist. Do not count on `id` being 1..n; `db:status` should count rows or compare `created_at` with the journal |
| S-4 | What is pending is decided by **journal `when` greater than the newest `created_at`** in the table (`dialect.js:56-62`), not by file name and not by hash. Shown: a new file whose `when` was set older than the newest applied row was skipped without a message (`applied by this call: 0`), and an applied file edited afterwards was not noticed (file hash `e0329899...`, stored hash `212fb07d...`, `RESULT: ok`) | MG-4 ("an applied file is never edited") is not enforced by the tool. | S-5 | Relative `schema` and `out` resolve against the **process directory**, not the config file (`Error  No schema files found for path config ['./schema.ts']` when run from another folder) | Run `drizzle-kit` with `apps/core-server` as the working directory (`npm run db:generate -w @dems/core-server` does), or write absolute paths |

| S-7 | On PostgreSQL 18.4 a delete refused by `ON DELETE RESTRICT` reports **SQLSTATE 23001**, not 23503; an insert with an unknown parent reports 23503 | Every foreign key of the contract is `ON DELETE RESTRICT` (K-2). An error map that knows only 23503 misses the delete case |
| S-8 | drizzle-orm wraps the driver error: `DrizzleQueryError`, with `code` and `constraint` on `error.cause` | The mapping of `ZA001`, `ZA002`, `23505`, `23514` in the server reads `error.cause`, and the error itself for plain `pg` |
| S-9 | Plain `pg` returns a `bigint` as a string; drizzle-orm `mode: 'number'` converts it.
