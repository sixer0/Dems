| S17-1 | tailwind-merge drops design font sizes | **Finding.** HeroUI's `tailwind-variants` merge turns `font-display text-display uppercase text-accent` into `card__title font-display uppercase text-accent` (proved with `cardVariants().title({ className })`): tailwind-merge knows only T-shirt font sizes and classifies `text-display` as a colour. Same for `text-h1`…`text-data`. **Fix here:** the app `cn()` registers the tokens via `extendTailwindMerge` (list exported from shared as `TYPOGRAPHY_FONT_SIZE_CLASSES`); on kit components the size token and the colour sit on separate elements (e.g. `Card.Title className="text-accent"` > `span.font-display.text-display`). tailwind-variants has no supported global hook for third-party kit components, so its internals were not patched | Affects every §2.7 `text-*` utility on web **and** HeroUI Native (same library).
